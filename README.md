# Python Projects

This is where I keep the Python stuff I've built while learning. Some of it is early practice from when I was starting out, and some is more built out.

What's in here:

- `ambassador-analytics-dashboard/` is a Flask dashboard I made to track my Google Student Ambassador events, signups, and reach, with charts. It has its own README inside with how to run it.
- `BMI_Calculator.py` is a simple BMI calculator.
- `Math_Quiz.py` is a quick math quiz that runs in the terminal.
- `TicTacToe.py` is two player tic tac toe.
- `Typing_Speed_Test.py` measures how fast you type.

The single file scripts just run with `python <file>.py`. The dashboard needs Flask installed first, and the steps are in its own README.
